ELISA'S BAGUIO TRANSIENT HOUSE — DESIGN PROTOTYPE

Open index.html in a modern browser for the visitor site.
Open admin.html for the admin dashboard.

Deploy both pages and the assets folder together on Cloudflare Pages or another static host.

IMPORTANT: This is a functional local demo, NOT a production booking system.
Booking requests and admin updates are stored only in the same browser's localStorage.
They will not synchronize between visitors, devices, or browsers.
The admin page has NO login protection. Do not publish it for real guest management.
No payment processor, email sending, or live backend is connected.
Photos are crops from the approved concept mockup and should be replaced with real property images.

For production, add Firebase Authentication, Firestore with security rules,
server-side booking conflict validation, and secure admin-only payment updates.
